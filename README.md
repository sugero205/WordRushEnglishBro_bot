# Word Rush

3D-раннер для изучения английских слов уровня B1–B2. Работает в браузере на телефоне и как Telegram Mini App.

**Играть:** https://sugero205.github.io/WordRushEnglishBro_bot/ · **Бот:** [@WordRushEnglishBro_bot](https://t.me/WordRushEnglishBro_bot)

Перед каждым забегом — 10 карточек слов и быстрая проверка. Потом слова выходят на тропу монстрами: нужно встать на полосу с верным переводом. В игре 5 глав (126 слов), можно добавлять свои слова, есть боссы, экзамены у ворот глав, магазин, задания дня и режим ХАРД.

## Что в репозитории

| Путь | Что это |
|---|---|
| `index.html` | игра целиком: код, стили, интерфейс |
| `lib/` | three.js r128 и загрузчики моделей |
| `models/` | 3D-модели: героиня, вампир, кот, волк, враги и босс, реквизит |
| `icon.png` | иконка сайта |
| `promo/avatar-640.png` | аватар бота |
| `promo/cover-640x360.png` | обложка Mini App для `/newapp` |

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
Через 1–2 минуты игра откроется по ссылке `https://sugero205.github.io/WordRushEnglishBro_bot/`.

## Подключение к Telegram-боту (@BotFather)

1. `/mybots` → выбрать бота → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → прислать ссылку на игру.
2. Там же: **Menu Button** → прислать ссылку → название кнопки: `Играть`.
3. `/setuserpic` → картинка `promo/avatar-640.png`.
4. `/setdescription` — текст, который видят до нажатия «Старт»:

   > Word Rush — 3D-раннер, в котором забытые английские слова стали монстрами. Перед каждым забегом — 10 карточек, потом слова выходят на тропу: выбирай полосу с верным переводом, бей волков мечом, побеждай боссов и открывай новые главы. Слова B1–B2, интервальные повторения, можно добавить свои слова. Нажми «Играть» 👇

5. `/setabouttext` — короткое описание в профиле бота:

   > 3D-раннер для английских слов B1–B2: карточки, забеги, боссы и свои слова.

6. Необязательно — прямая ссылка на игру: `/newapp` → бот → название `Word Rush` → описание → фото `promo/cover-640x360.png` → GIF можно пропустить (`/empty`) → ссылка на игру → короткое имя, например `play`. Ссылка будет вида `t.me/WordRushEnglishBro_bot/play`.

## Сохранение прогресса

- **В Telegram** прогресс хранится в облаке Telegram (CloudStorage) и одинаков на всех устройствах, где открыт этот бот.
- **В браузере** прогресс хранится на устройстве. В настройках игры можно скачать файл сохранения или скопировать код и перенести прогресс.

## Что игра делает в Telegram

- разворачивается на всю высоту, свайп вниз не сворачивает приложение;
- вибрация через Telegram — работает и на iPhone;
- кнопка «Назад» в шапке закрывает меню или ставит забег на паузу;
- во время забега Telegram спрашивает подтверждение перед закрытием.

## Обновление игры

Замените файлы в репозитории новыми и сделайте коммит в `main` — Pages обновится сам за 1–2 минуты. Боту ничего менять не нужно.
